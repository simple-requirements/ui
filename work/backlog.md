I did not start the frontend, did not run `pnpm build`, and did not execute the full test suite in this environment. The `Coverage %` values are static-analysis estimates, not runtime verification results.

## Coverage percentage scale

- `0%`: no relevant frontend implementation found.
- `1–30%`: only generated client code, helper code, or a small technical foundation exists.
- `31–60%`: a visible UI path exists, but major acceptance criteria are missing.
- `61–85%`: the main UI/data path exists, but important edge cases, routes, tests, or related views remain.
- `86–99%`: nearly complete, but at least one acceptance criterion is still missing.
